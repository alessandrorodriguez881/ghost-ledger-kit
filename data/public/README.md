# Public data

This folder holds **official public data under an open licence**. It is the only place in the
repository where data is neither synthetic nor generated by a script of this project (Finance
Rule 6). It contains no personal data and no figure of any user.

## `ine_cpi_ipc290751.json`

| Item | Value |
|---|---|
| Source | INE (Instituto Nacional de Estadística), public JSON API `https://servicios.ine.es/wstempus/js/ES/DATOS_SERIE/IPC290751` |
| Series | `IPC290751`, Nacional. Índice general. Índice (table 76125) |
| Index | monthly consumer price index (IPC), base 2025 (2025 average = 100), classification ECOICOP v2, three decimals |
| Period | 2017-01 to the latest published month, every month, no gap |
| Status | copied from the API for every month (`Definitivo` or the provisional status as published) |
| Licence | CC BY 4.0 |

The old base-2021 series `IPC251852` stops in December 2025 and is **not** used.

### Licence and attribution

The snapshot is INE data. It keeps the INE licence and is not covered by the repository MIT licence.
The INE legal notice applies CC BY 4.0 to its content (the page footer mentions CC BY-SA 4.0; the
text of the notice governs). The attribution the INE asks for on processed data is:

Elaboración propia con datos extraídos del sitio web del INE: www.ine.es

Licence: CC BY 4.0

The INE does not take part in, sponsor or support this reuse.

The Zombie Subscriptions page shows this attribution once, below its alerts, and the showcase
Home page carries it in one line. The comparison it supports is context for a price increase that
was already detected; it never decides whether an alert fires.

### How the snapshot is made and refreshed

The apps, the tests and the explanation layer never call the network: they read this committed
file. Only the developer runs the fetch script, which uses the Python standard library, makes one
request, checks the result and replaces the file only when every check passes:

```powershell
python scripts/fetch_ine_cpi.py
```

Run it again once the INE publishes a new month (October 2026 is normally published in mid
November), read the one-line result, check `git status` and commit the file. No test needs to
change: the demo tests compute their expectations from the snapshot.

### What is in the file

A UTF-8 JSON file with LF line endings: the series metadata (code, name, table, base year,
classification, `retrieved_on`, licence, attribution, non-endorsement text), `first_month`,
`last_month` and a `values` list, oldest first, of `{"month", "value", "status"}`. Every `value` is
a string with exactly three decimals, never a float. `tests/public_data/test_ine_cpi_snapshot.py`
pins the figures of 2026-08 and 2026-09 and the texts above, and `tests/test_public_data_docs.py`
checks that this file, the root `README.md` and the snapshot carry the same attribution.
