Source facts, checked on 9 November 2026: the INE (Instituto Nacional de Estadistica) publishes the Spanish CPI (IPC). Since January 2026 the CPI uses base 2025 (2025 average equals 100) and the ECOICOP v2 classification, with retrospective series; the old base 2021 series IPC251852 stops in December 2025 and must not be used. The national general index level is series IPC290751, named Nacional. Indice general. Indice, in table 76125, monthly, values with three decimals, for example 2026 M09 104.978 and 2026 M08 104.638, status Definitivo. The public JSON API is https://servicios.ine.es/wstempus/js/ES/DATOS_SERIE/IPC290751 with parameter nult for the last n periods; each Data entry has Fecha (epoch milliseconds), FK_Periodo (month 1 to 12), Anyo and Valor. Licence: the INE legal notice applies CC BY 4.0 to its statistics, requires the attribution Elaboracion propia con datos extraidos del sitio web del INE: www.ine.es for processed data, and forbids suggesting that the INE takes part in, sponsors or supports the reuse.
Specify: (1) a script scripts/fetch_ine_cpi.py that uses only the standard library to download the series (from January 2017 to the latest month) and writes a committed snapshot data/public/ine_cpi_ipc290751.json with the series code and name, base 2025, the API URL, the retrieval date, the licence and attribution texts and the monthly values as strings with their status; tests never touch the network and validate the committed snapshot (contiguous months, positive values, required metadata); the developer runs the script and commits the result.
